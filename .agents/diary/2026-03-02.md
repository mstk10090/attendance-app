# 日報 2026-03-02（月）

## 作業内容

### 1. 出退勤打刻・申請関連のバグ修正
- **日付跨ぎ退勤バグ**: activeItemを当日のみから全レコード検索に変更し、日付跨ぎ時に退勤できない問題を修正
- **取り下げ機能の修正**: 承認待ちの全レコードで取り下げ可能にし、行クリック＋編集フォーム両方に対応。イベントオブジェクトが渡されるバグも修正
- **未退勤＋承認待ち表示**: 未退勤かつ承認待ちの行にも取下げボタンを表示するよう修正

### 2. 出退勤画面のUI改善
- **未退勤の日付リスト化**: 未退勤をSTATSカード内で日付リスト表示に変更
- **CSSリセット強化**: PC間のレイアウト差異を防ぐためグローバルCSSリセットを追加
- **STATSカードに日付表示**: 遅刻・欠勤・早退のカードに具体的な日付を表示
- **未申請バッジ**: パルスアニメーション付きデザインに変更

### 3. 残業・申請バリデーション修正
- **残業理由の自動選択**: 残業検出時に理由自動選択＋残業理由テキスト必須化
- **残業サブ理由バグ**: サブ理由（業務上必要等）選択時にテキスト入力不要に修正

### 4. 勤務時間計算の修正
- **派遣/バイト時間計算**: approved限定から全レコードに計算対象を拡大
- **全ユーザー対応**: 派遣/バイト時間をシフトデータベースから自動分類する方式に変更
- **日単位計算**: 派遣/バイト時間を日単位計算+30分丸め+出勤日数追加+表記統一
- **遅刻判定バグ**: `>=` → `>` に修正。定時出勤（09:00）がシフト開始（09:00）と一致して遅刻扱いされ、バイト分から30分削られていた問題を修正

### 5. レポート月ナビの修正
- **2月スキップバグ**: `addDays(-30)` → 月単位移動に変更。2月が28日のため30日引くと1月に飛ぶ問題を修正

### 6. 管理者勤怠画面の大幅改善
- **未出勤バッジ**: シフト予定者を赤帯「未出勤」バッジ付きで表示
- **shiftMap非同期問題**: shiftMapロード後にfetchAttendancesを再実行するuseEffect追加
- **承認済み表示強化**: ✅承認済バッジ（白文字＋緑背景）に変更、行背景も濃い緑(#d1fae5)に
- **操作ボタン整理**:
  - 承認済み → 承認取消ボタンのみ
  - 未承認 → 承認 + 修正 + 再提出
  - 再提出済み → 承認 + 修正（再提出ボタン非表示）
  - 未出勤 → 修正 + 欠勤登録
- **承認取消機能**: 承認済みを承認待ちに差し戻す機能を追加（確認ダイアログ付き）
- **管理者編集フォーム**: モーダル内に出勤/退勤/休憩の直接編集セクション追加。保存時にadminEditedフラグを設定
- **取り下げのconfirm削除**: window.confirmがモーダル上で効かない環境対策

### 7. API・インフラ修正
- **確定シフトAPI URL修正**: `/shifts/confirmed` → `/shift/confirmed` に修正
