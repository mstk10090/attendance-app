# 日報 2026-03-14（金）

## 作業内容

### 1. 遅刻+早退の個別表示・個別取消対応
- 遅刻と早退が同時発生した場合（`shiftCheck === "both"`）、これまで一括表示・一括取消だったものを個別に分離
- 遅刻・早退それぞれに個別の「取消」ボタンを表示、個別に理由入力・取消が可能に
- 取消済みの場合は取り消し線付きで個別表示（例: `遅刻（取消済）` / `早退（取消済）`）
- **対象ファイル**: `src/pages/admin/AdminAttendance.jsx`

### 2. シフト読み込みのキャッシュ優先化
- 全ページ（AttendanceRecord / StaffReport / MyPage）でシフトデータの読み込みをキャッシュ優先に変更
- localStorageに前回のシフトデータがあれば即座に表示し、バックグラウンドでGoogle Sheets/DynamoDBから最新データを取得
- タブ切り替え時の待ち時間を大幅に短縮
- 退勤時にシフトが見つからない場合、`shiftLoaded`フラグに関係なく必ず再取得を試みるよう改善
- **対象ファイル**: `src/utils/shiftParser.js`, `src/pages/AttendanceRecord.jsx`, `src/pages/StaffReport.jsx`, `src/pages/MyPage.jsx`

### 3. ログイン後のリダイレクト先修正
- ログイン成功時に`/report`などに留まってしまう問題を修正
- `handleLoginSuccess`内で`window.history.replaceState`を使い、ログイン後は必ず出退勤入力ページ（一般: `/attendance`, 管理者: `/admin/attendance`）へ遷移
- **対象ファイル**: `src/App.jsx`

### 4. マイページの総勤務時間・出勤日数カード削除
- マイページから「総勤務時間」と「出勤日数（実績/規定）」のカードを削除（算出が不正確なため）
- 遅刻・欠勤・早退セクションとデフォルト設定はそのまま維持
- **対象ファイル**: `src/pages/MyPage.jsx`

### 5. 再提出依頼ステータスの表示修正
- 再提出依頼（`resubmission_requested`）のある日がHistoryReportで「シフト未出勤」と表示される問題を修正
- `isShiftMissing`の判定条件から`resubmission_requested`と`sa_return_staff`を除外
- 再提出依頼の行を紫背景（`#faf5ff`）で表示するよう追加
- **対象ファイル**: `src/components/HistoryReport.jsx`

### 6. 重複userIdのデータ移行（全スタッフ対象）
- 小河原豪さんの3/12再提出データがレポートに表示されない問題を調査
- 原因: 同一スタッフに2つのuserIdが存在（旧形式`user-2026xxxx`と新形式`user-177xxxx`）し、再提出データが旧userIdに紐付いていた
- 全スタッフを調査した結果、**45名に重複が発見**
- 旧userIdのデータ **184件** を現在のuserIdに一括移行（全件成功、失敗0件）
- これにより全スタッフのレポートで過去の勤怠データが正しく表示されるようになった
