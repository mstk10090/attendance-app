# 勤怠システム開発メモ

## ⚠️ 最重要: シフト取得ロジック

**スプレッドシートの値は当日中に変わる。**
- 元のシフト: `17:00-22:00`
- 遅刻したら記録のために `17:30-22:00` に書き換えられる
- **変更後の値を取得したら遅刻判定が崩れる**
- だから**変更前の値**（前日23:30のCronで確定保存した値）で判定する

**DynamoDB確定シフト（23:30 Cron）の意味:**
→ スプレッドシートが書き換えられる前の「本来のシフト」を保存している
→ この値が遅刻/早退判定の基準になる

**localhostの注意:**
→ localStorageキャッシュやDynamoDBデータがないため、スプレッドシートの「現在値（変更後）」を使ってしまう
→ 本番環境とlocalhostでシフト表示がずれる場合がある（本番が正）

## 重要ルール

### 勤怠確認シート（AdminAttendanceSheet）
- **バイト時間のみ表示する**（派遣時間は表示しない）
- 勤怠管理ページで派遣/バイトを分離計算した上で、バイト時間だけを勤怠確認シートに反映
- 例: 伊佐3/6 → 派遣8.0H+バイト1.5H → 勤怠確認シートには **1.5** のみ表示

### 勤怠管理ページ（AdminAttendance）
- 派遣とバイトを分離して表示（派遣X.0H / バイトX.0H）

### 欠勤
- 欠勤には承認は不要（承認フロー対象外）
- 欠勤の表示は「欠勤」バッジ（マルーン色背景）

### 承認フロー
- 通常管理者（井本さん等）: 承認ボタン表示 → 承認済みにする
- 上位管理者（マサトキさん）: 勤怠管理ページでは承認ボタン非表示 → 勤怠確認で最終承認

### 取消機能
- 遅刻取消: 判定列に「取消」ボタン
- 早退取消: 判定列に「取消」ボタン
- 欠勤取消: 判定列に「取消」ボタン
- 取消済みは取消線+グレーアウトで表示

### 未退勤
- 未退勤では申請不可（欠勤以外）
- 退勤してから申請する流れ
